# Дозор — панель системы охраны на Go

Видео в панели — **сама штатная страница вашего go2rtc**:
[http://127.0.0.1:1984/stream.html?src=luckfox](http://127.0.0.1:1984/stream.html?src=luckfox).
Она встроена через iframe. Режим воспроизведения выбирает go2rtc автоматически, как при открытии этой ссылки отдельно. Панель не добавляет перекодирование, прокси, обработку RTP или собственный видеобуфер.

## Запуск

Для запуска в контейнерах используйте `docker-compose.yml` в корне репозитория. См. [инструкцию Docker](docs/DOCKER.md). Ниже описан запуск готовых программ в Windows.

1. Включите плату и роутер.
2. Запустите свой go2rtc с потоком `luckfox`. Для готового архива используйте `scripts/start.cmd`; при сборке из Git сначала поместите официальный `go2rtc.exe` версии 1.9.15 в `dist/go2rtc/`. Если go2rtc уже работает, оставьте это окно открытым.
3. Запустите **`scripts/start-admin.cmd`**.
4. Откройте [админку](http://127.0.0.1:8080). После обновления сборки нажмите `Ctrl+F5`.
5. Для проверки оставьте один плеер: закройте отдельную вкладку трансляции, когда откроете её в панели.

`start-admin.cmd` запускает только `dist/guard-admin.exe` и не управляет процессом go2rtc. `scripts/start.cmd` сохранён для самостоятельного запуска комплектного go2rtc; не запускайте его одновременно с уже работающим экземпляром на порту 1984.

Чтобы остановить панель, нажмите `Ctrl+C` в её окне. Ваш отдельный go2rtc продолжит работу. «Остановить» закрывает встроенный плеер, а «Запустить» применяет выбранный источник и открывает просмотр. Камера и процесс go2rtc не перезапускаются; поток не удаляется при остановке просмотра.

## Как идут данные

```text
Luckfox / rkipc :554 ── RTSP по Wi-Fi ──> ваш go2rtc :1984
                                              │
                           исходный кодек → штатный плеер в iframe
                                              │
Go-сервер :8080 ── интерфейс, настройки, журнал ── браузер
       │
       └── GET /api/streams?src=luckfox → только чтение счётчиков go2rtc
```

Go2rtc сам согласует WebRTC/MSE и другие поддерживаемые им способы просмотра. URL встроенной страницы не содержит принудительного `mode`. Текущий входящий поток — `rtsp://95.163.220.75:8554/mystream`; настройки кодирования камеры панель не изменяет.

Начальный источник в go2rtc.yaml:

```yaml
streams:
  luckfox: rtsp://95.163.220.75:8554/mystream
```

Чтобы изменить источник, отредактируйте поле **«Источник видео»** над плеером и нажмите **«Применить и запустить»** или Enter. Также можно изменить адрес в разделе «Настройки системы» и сохранить. Панель сохраняет ссылку в `data/settings.json`, применяет её к потоку `luckfox` через API go2rtc и перезагружает плеер. Перекодирование не добавляется.

Переменная `CAMERA_RTSP_URL` задаёт источник при первом запуске. После изменения в интерфейсе сохранённая ссылка имеет приоритет и восстанавливается в go2rtc при запуске панели. YAML go2rtc не переписывается; настройки хранятся в каталоге данных или Docker volume. Если просмотр отключён, сохранённый источник применяется при его запуске.

## Консоль камеры

В разделе **«Консоль камеры»** доступен интерактивный SSH-терминал: введите адрес платы, порт 22, пользователя root и существующий пароль SSH. Поддерживаются стрелки, Ctrl+C, nano/top, изменение размера и полный экран. Пароль не сохраняется в настройках; известные SSH-ключи проверяются. Сеанс остаётся открытым при переходе в другие разделы панели и закрывается по кнопке или при закрытии вкладки.

[Устройство, протокол, проверки и использование консоли](docs/CAMERA_CONSOLE.md).
## Возможности и ограничения

- Прямая трансляция через неизменённую страницу go2rtc, со штатными кнопками звука, паузы и полного экрана.
- Входящий видеобитрейт, кодек и число зрителей из API go2rtc. API-запрос счётчиков не создаёт дополнительного зрителя или RTSP-сеанса.
- Поиск, фильтры, SSE-обновления и экспорт журнала JSONL.
- Настройки камеры для агента, confidence, таймеры, сохранённая зона наблюдения и желаемый режим охраны.
- API агента для получения политики, записи событий и телеметрии с подтверждением версии политики.

Плеер находится на другом origin (порт 1984 вместо 8080). Браузер запрещает панели читать его DOM и кадры. Поэтому FPS декодера, пропуски кадров, задержка и видеобуфер не отображаются; кнопки снимка и рисования ROI недоступны. Сохранённая зона остаётся в настройках и передаётся агенту. Статус «Плеер go2rtc открыт» означает открытие страницы, а не доказанное получение кадра. Ошибки видеопотока смотрите в самом плеере и в окне go2rtc.

Плеер использует имя/IP из адресной строки панели и порт 1984. На этом имени/IP должен быть доступен go2rtc. При открытии `127.0.0.1:8080` сохраняется прежний адрес `127.0.0.1:1984`.

Панель не выполняет YOLO. Без подключённого агента показатели детектора показывают отсутствие телеметрии. Кнопка охраны сохраняет запрос, а подтверждение приходит от агента.

## Сборка

Нужен установленный Go 1.26+. Если рядом с проектом есть переносимый SDK `../.tools/go`, `scripts/build.cmd` использует его; сам SDK не входит в Git-репозиторий.

```powershell
.\scripts\build.cmd
.\scripts\test.cmd
.\scripts\start-admin.cmd
```

HTML/CSS/JS встроены через `go:embed`. После их правки пересоберите сервер, перезапустите его и обновите вкладку. Node.js нужен только для проверки JS (`npm run check`), не для работы приложения.

## Настройки сервера и файлы

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `-listen` | `127.0.0.1:8080` | HTTP-адрес панели |
| `-data` | `data` | Каталог настроек и журнала |
| `-go2rtc-url` | `http://127.0.0.1:1984` | Адрес API go2rtc со стороны сервера; в Compose — `http://go2rtc:1984` |
| `GUARD_ADMIN_PASSWORD` | пусто | Basic-пароль пользователя admin, от 12 байт; обязателен вне loopback |
| `GUARD_AGENT_TOKEN` | пусто | Bearer-токен агента, от 24 байт; без него API агента отключён |
| `CAMERA_RTSP_URL` | пусто | Начальный источник для первого запуска; сохранённая в интерфейсе ссылка имеет приоритет |
| `CAMERA_SSH_HOST` | `192.168.1.199` | Начальный адрес SSH-консоли платы, независимо от адреса RTSP-сервера |

`data/settings.json` хранит настройки; `data/events.jsonl` — журнал. Не удаляйте их при обновлении сборки. Не передавайте их вместе с исходниками: они могут содержать адреса с паролями и реальные события.

## Если видео тормозит

Для отдельной проверки нагрузки подготовлен [обратимый профиль H.265 / 720p25](docs/LOW_LATENCY_TRIAL.md). Он применяется вручную на плате, сохраняет исходный INI и не меняет go2rtc или сетевые настройки. Сам факт подготовки профиля не означает, что плавность уже улучшилась.

Сравните один и тот же плеер отдельно и в панели, открывая их по очереди. Ошибки `RTP header size insufficient` и `read tcp ...:554: i/o timeout` относятся к получению RTSP в go2rtc. Встраивание страницы не исправляет входящий поток и не доказывает причину смазывания. Не увеличивайте тайм-аут и не меняйте кодек наугад: сначала отделите проблему поступления данных от настройки выдержки/сжатия камеры.
